# お城さんぽ 共通素材・共通ルール

お城さんぽシリーズ（大阪城・姫路城・松本城・彦根城・犬山城、今後の松山城・安土城・熊本城・備中松山城）で
共通に使う素材と、どの城でもそろえる作りのルールをまとめた場所です。

公開パス: `https://32miya.github.io/oshiro/common/assets/`
各城のコードからは **`/oshiro/common/assets/…`**（ルートからの絶対パス）で読み込みます。
全城が `32miya.github.io` の同じサイト内にあるので、一度読んだ素材はブラウザに残り、2城目からは読み込みが速くなります。

## 2. どの城でもそろえる作り

※ 共通の作りを入れるときも、その城にしかない特徴（大阪城の伏虎や豊臣期の金の装飾、姫路城の大柱や長壁神社、松本城の隠し階、彦根城の破風の間、犬山城の段梯子など）は変えずに残す。

1. **天守の窓から外が見える**
   各階の外壁に本当の開口をあけ、窓枠と格子をはめる。中から格子越しに城下が見え、外から見ても窓の奥に室内がある。
   - 大阪・松本: `keepWindows(T)`（index.html の「天守の窓（お城さんぽシリーズ共通仕様）」）。
     層ごとの外壁を `cut:true` にして作らずにおき、`T.win` の指定（壁画像1枚分の中の窓の位置・床からの高さ・枠と格子の材質）で穴のあいた壁として作り直す。
   - 姫路・彦根・犬山: それぞれの天守の作りに合わせて同じ考え方で実装済み。
   - 窓のない階（松本城3階のような隠し階）は窓をあけない。
   - 中が博物館になっている現代の天守（大阪城天守閣など）は、窓は外観だけにして中から外は見せない（展望台の階だけ外が見える）。
2. **階段の先が見える（吹き抜け）**
   - 階段の上の床と天井の穴を、階段より左右と後ろに広くあける（`wellR` / `stairWell`）。上の階は穴のまわりに手すりを回し、落ちないように当たりを付ける。
   - 吹き抜けの上を通る梁や小壁は、その所だけ切る（姫路 `cutBox`、彦根）。
   - 階段を上り下りしている間は、進む向きに合わせて目線を少し上下させ、行き先の階が見えるようにする（`P.sp`）。
3. **入口から奥が見える**
   - 天守台の石垣に入口の穴を本当にあける（`frustumDoorGeo` / 姫路は `moatWallDoorGeo`）。入口を黒い板でふさがない。
4. **素材は共通のものを先に使う**: 石垣・瓦・床・襖絵・人物などは、まずこの一覧から選ぶ。新しく描いた素材で他の城でも使えるものは、ここに追加して一覧に書く。
5. **お城選びへ戻る**: 各城の index.html の末尾に `oshiro-portal:begin`〜`end` のブロックを入れる（`../castle-snippet.html`）。
6. **読み込めないときも動く**: 共通素材が読めないときは、手描き（コードで描いた）の材質のまま動くようにする。
