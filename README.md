# HTMMゲーム館

GitHub に置いた自作ゲームを一覧で紹介し、画像をタップするとそのままゲームが起動するポータルサイトです。
GitHub Pages（無料）で公開し、プレイ回数・コメント・表示設定は Google Apps Script（無料）に保存します。

## できること
- ゲーム画面のサムネイル・簡単な説明・ジャンル・開発状況（開発完了／開発中）・NEW表示
- 画像をタップ → そのゲームが新しいタブで起動（プレイ回数を自動カウント）
- プレイ回数ランキング（上位3本に王冠）・サイト全体の総プレイ数
- 製作者に感想を送るフォーム（ログイン不要、300文字まで。コメントは管理画面でだけ読める）
- 暗証番号つきの管理画面
- 並び替え：更新が新しい順／プレイ回数／コメント数／名前順／ジャンル順
- ジャンル絞り込み・開発状況の絞り込み・キーワード検索
- ゲームごとの共有URL（`…/#g=rokuro` で詳細が開く）
- GitHub Pages を有効にした新しいリポジトリは自動で一覧に追加（最初は「準備中」）

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体 |
| `games.json` | ゲーム一覧（タイトル・説明・ジャンル・状態・画像） |
| `config.js` | サイト名・サーバーURL |
| `thumbs/` | ゲーム画面の画像 |

## 1. GitHub Pages で公開する（約5分）

**おすすめ：リポジトリ名を `32miya.github.io` にする**と、サイトのURLが `https://32miya.github.io/` になります。
（ほかの名前、たとえば `game-portal` にした場合は `https://32miya.github.io/game-portal/` になります）

1. GitHub で新しいリポジトリ `32miya.github.io` を作成（Public）
2. このフォルダの中身を全部アップロード（「Add file」→「Upload files」にドラッグでもOK）
3. リポジトリの「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 1〜2分後に `https://32miya.github.io/` を開くと表示されます

※ サーバー未設定の間は「デモモード」で、プレイ回数は見た人の端末の中だけで数えます。

## 2. プレイ回数・コメント・管理画面を動かす（Google Apps Script・無料）

サーバーのプログラム（`HTMMゲーム館_サーバー.gs`）は暗証番号が入っているので、**このリポジトリには置いていません**。

1. https://script.google.com を開き「新しいプロジェクト」
2. 最初からある `function myFunction() {}` を全部消し、`HTMMゲーム館_サーバー.gs` の中身を貼り付けて保存
3. 上の関数選択で `setup` を選んで「実行」→ アクセスを承認（「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」）
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」で表示される **ウェブアプリURL**（`https://script.google.com/macros/s/…/exec`）を `config.js` の `apiUrl` に貼る

コメントは Google ドライブにできるスプレッドシート「HTMMゲーム館 コメント」にも保存されます。

### 管理画面
サイト下の「管理者」から暗証番号を入れると開きます（`https://32miya.github.io/#admin` でも可）。
- ゲームごとに「公開／準備中／非表示」「開発中／開発完了」を切り替え
- タイトル・説明・ジャンルの編集
- 全端末合計のプレイ回数の確認
- コメントの閲覧・既読・削除
- 「この端末のプレイを数えない」（自分のテストプレイを除外）

### サーバーのプログラムを直したとき
「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。（「新しいデプロイ」にするとURLが変わってしまいます）

### 注意
「準備中」「非表示」はこのサイト上での表示を切り替えるだけです。ゲーム本体のURL（`https://32miya.github.io/リポジトリ名/`）を知っている人は直接開けます。完全に止めたいときは、そのリポジトリの Settings → Pages で公開をやめてください。

## ゲームを追加・編集するには

`games.json` に1ブロック追加するだけです。

```json
{
  "id": "rokuro",
  "title": "ろくろ",
  "genres": ["シミュレーション"],
  "status": "dev",
  "desc": "回る粘土を指で形づくる陶芸ゲーム。",
  "thumb": "thumbs/rokuro.webp",
  "emoji": "🏺",
  "updated": "2026-10-23"
}
```

- `id` … GitHub のリポジトリ名（URLは自動で `https://32miya.github.io/<id>/` になります）
- `status` … `done`＝開発完了 ／ `dev`＝開発中
- `genres` … 複数指定OK。新しいジャンル名を書けば絞り込みボタンも自動で増えます
- `thumb` … 画像のパス。省略すると `emoji` とタイトルのカードになります
- `url` … GitHub Pages 以外の場所にあるゲームのときだけ指定
- `vis` … `public`＝公開 ／ `soon`＝準備中 ／ `hidden`＝非表示（管理画面で変更した内容が優先されます）
- `updated` … GitHub から最終更新日を取れなかったときの予備

サムネイル画像は縦長（4:5くらい）がきれいに収まります。ゲーム画面をスマホでスクリーンショットして `thumbs/` に入れてください。

自動追加したくないリポジトリは `config.js` の `exclude` に名前を書いてください。
